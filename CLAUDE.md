# ut-plugin-faq — rules

Page-type plugin for Universal Till. Docs repo ADRs are binding:
ADR-0001 (runtime none/wasm — never add an unnecessary binary; this plugin
is asset-only, the POS renders content/<locale>.json natively), ADR-0002
(entry types), ADR-0009 (plugin repo naming + pipeline). Manifest contract:
docs repo reference/plugin-manifest.md. Bump the manifest version and tag
`v<version>` to release; never publish by hand.
